## Changes Made This Session

### Change 1: Raise force_rampdown_start from 12N → 16N
**Why**: Normal insertion resistance is ~14N. With rampdown starting at 12N, the robot was already slowing down during normal insertion. This caused artificial stalls. Now the robot pushes through normal resistance at full speed. Only slows if force reaches unusual levels.

### Change 2: Raise force_rampdown_full from 18N → 19N  
**Why**: Gives more range for proportional slowdown (16-19N = 3N range instead of 12-18N = 6N). The 20N penalty threshold is the hard limit, so we stop just below it.

### Change 3: Throttle debug prints to every 5th observation
**Why**: At ~30Hz, printing every observation floods the terminal. Every 5th = ~6Hz, still readable but not overwhelming. Full detail still shown for phase transitions.

### Change 4: Lower hover_height from 0.03m → 0.02m
**Why**: Closer alignment = less drift during initial descent into port. 2cm is enough clearance for alignment.

### Change 5: Reduce insertion_dwell from 2.0s → 1.5s
**Why**: Faster episode completion for data collection. 1.5s is enough to confirm stable insertion.

### Change 6: Reset stall detection on phase transitions
**Why**: Stall detection state wasn't always being reset when transitioning between phases, which could cause stale triggers.

### Change 7: Improve SEARCH to use expanding spiral
**Why**: Fixed-radius circle might miss the port if offset is different from the radius. Expanding spiral covers progressively larger area.
